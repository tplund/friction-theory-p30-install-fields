# Nature and Nurture in a Language Model: Installable Value Fields, Intrinsic Capacity, and the Forward-Consolidation Boundary

**Tomas Pødenphant Lund**
ORCID 0009-0000-4724-2427

*Preprint. Independent researcher. Target venue: a cognitive-science outlet that uses large language models as a model of cognition (e.g. Computational Brain & Behavior / Cognition).*

## Abstract

Behavioural Friction Theory (BFT) decomposes the forces that govern a bounded decision system into a small set of cognitive *fields* — Safety, Meaning, Ability, and Effort. We ask whether these fields are intrinsic properties of a cognitive substrate or the generic product of that substrate's exposure to experience, and we use a large language model as a controllable test substrate to answer it. We report that the two *value* fields (Safety, Meaning) can be installed into a base model by fine-tuning on experience-like data, and that they install as *graded intrinsic* directions rather than as the ceiling-level role-play that prompting elicits. The two *capacity* fields (Ability, Effort) are not raised by this same value-disposition route: capacity is the substrate's intrinsic capacity-against-demand match (the cross-substrate inverted-U), and a competence *disposition* fine-tune — carrying no skill-targeted training — yields only an expressive claim, not graded capability. (Skill-targeted training is a different regime that can raise the ceiling; our claim is the narrow one, that installing a *value-disposition* does not.) The asymmetry maps onto the nature/nurture distinction: the value channel is what disposition-fine-tuning installs, the capacity ceiling is the intrinsic substrate it does not move. We then show the bridge between them — an installed value-disposition (self-efficacy) gates the *realisation* of a fixed capacity ceiling: fine-tuning a model toward helplessness lowers realised performance monotonically with model capacity (Qwen2.5 7B/14B/32B: realised 0.95 → 0.77 → 0.29) while latent capability stays flat, and this gating is induced by fine-tuning where prompting cannot. We argue that a principal difference between this LLM and a human substrate, with respect to growing these fields, is forward consolidation: the model cannot store experience forward across sessions. We frame this as a hypothesis with a named falsifier — supply that storage and the same fields should grow — not as a demonstrated result, and we acknowledge other standing differences (embodiment, online/recurrent control, neuromodulation, evolved fast-timing priors). The contribution is the deflationary substrate-universality *hypothesis* — that the fields are the generic product of storage × experience — for which the install machinery is the demonstration apparatus, not the finding.

## 1. Introduction

Behavioural Friction Theory treats any bounded decision system — a person, an animal, a model — as resolving competing routes under a small number of organising forces, which it calls fields: Safety (the orientation toward predictability and away from threat), Meaning (the value-direction that says what matters), Ability (the match between the substrate's capacity and the task's demand), and Effort (the cost of computation itself). The companion papers develop each field, its friction signature, and the race dynamics that resolve them (Lund 2026a, 2026f, 2026n).

A natural and consequential question is whether these fields are *given* — intrinsic structure that a cognitive system has by construction — or *grown* — the generic residue of a substrate exposed to experience and able to consolidate it. The question matters because it determines what is universal about the theory. If the fields are species-specific adaptations, BFT is a theory about human (or animal) cognition. If they are the generic product of any consolidating substrate meeting experience, the framework is substrate-universal, and a language model becomes more than a metaphor for cognition — on this hypothesis a controllable instance of the same abstraction. We are careful (§7.1) to license this only as a simplified model that isolates one computational principle, not as a claim of identity between the model's mechanisms and human cognition.

We take the second position and test it constructively. Where a companion programme subtracts structure from the human case to isolate what a given field requires (Lund 2026ai), we do the inverse: we start from a substrate that has not had the fields installed over our material — a base model carries rich linguistic priors from pre-training, but no installed Safety or Meaning disposition over the (often invented) content we use — and install them, one at a time, by exposing the model to experience-like data and consolidating that exposure into the weights through fine-tuning. The model becomes a controllable model organism for the field ontology — install a field, remove it, dose it, and read off the friction and race signatures the theory predicts.

The central empirical structure we report is a *2+2 asymmetry* that maps exactly onto nature and nurture. The two value fields, Safety and Meaning, are installable: experience-fine-tuning grows them as graded, intrinsic directions in the substrate. The two capacity fields, Ability and Effort, are not moved by that route: they are the substrate's intrinsic capacity-against-demand relation (whose signature, the inverted-U, recurs across substrates and tasks (Lund 2026g)) and the intrinsic cost of computation. Asking to raise a capacity ceiling *by asserting competence* is a category error — like installing more memory by saying so — and when we try, the apparatus returns only an expressive claim with no graded capability behind it. (This is a claim about the value-disposition route only; skill-targeted training, which does raise task performance, is a separate regime we do not test.) The same machinery that installs the value fields does not move the capacity fields, on the same model, in one figure.

We then close the gap between the two halves. Nature and nurture are not independent: in humans, a learned value-disposition modulates how much of a fixed capacity is realised. We show the homologue in the model. A fine-tuned self-efficacy disposition gates *realised* performance through a give-up/avoidance threshold while leaving *latent* capability untouched, and the gating grows monotonically with the model's capacity — the more capacity there is to under-use, the more an installed "I cannot do this" suppresses its realisation. Crucially, fine-tuning installs this gate where prompting cannot: telling a compliant model it is incompetent does not make it give up; fine-tuning it to helplessness does.

Finally we name the one principled difference between this substrate and a human one. A standard language model cannot consolidate experience forward across sessions; it has no mechanism to store today's exposure into tomorrow's weights (Lund 2026a). That missing capability — forward consolidation — is, we argue, a principal part of the human/LLM boundary for growing these fields, though not the only difference (embodiment, online/recurrent control, neuromodulation, and evolved fast-timing priors are real and discussed in §7.2). Supply it (a developmental "sleep"-fine-tuning loop) and the model should, on our hypothesis, grow the same field characteristics ontogenetically. We do not demonstrate that loop here; we state it as a predicted consequence the theory invites, with an explicit falsifier (§7.2).

### 1.1 What is new, and what is method

Installing a disposition into a language model by fine-tuning, and showing that fine-tuning produces a deeper and more graded trait than prompting, is established. Open Character Training fine-tunes open models into value-laden personas and reports fine-tuning > steering > prompting with little capability loss (Maiya et al., 2025); persona and steering vectors install trait directions that colour processing (Chen et al., 2025; Zou et al., 2023; Turner et al., 2024; Panickssery et al., 2024; Bhandari et al., 2025); and using an LLM as a controllable model organism for a psychological variable is an existing programme (Caron & Srivastava, 2023). We use this machinery as our *method* and position against it explicitly; treating the install itself as the contribution would be re-discovering published work.

The contribution is the theory the apparatus demonstrates: (i) the BFT field ontology tied to installed directions with friction/race signatures; (ii) the 2+2 value-installable / capacity-intrinsic dissociation as a *falsifiable structural prediction* — a theory that predicts a *class* of properties (the capacity ceilings) that a value-disposition install does not move, which the persona-vector literature does not predict; (iii) the nurture-gates-realisation result (self-efficacy as a realisation-gate on a fixed ceiling); and (iv) the deflationary substrate-universality hypothesis, with forward consolidation proposed as a principal human/LLM boundary.

### 1.2 Related work

We situate the contribution against five neighbouring literatures so that what is new is not "installation works."

*Disposition installation by fine-tuning.* The closest prior art installs value-laden personas or traits by fine-tuning and reports that fine-tuning yields a deeper, more graded, more robust trait than prompting while preserving general capability — Open Character Training (Maiya et al., 2025) and persona / activation-steering vectors (Chen et al., 2025; Bhandari et al., 2025). The fine-tuning-deeper-than-prompting ordering is established directly by Open Character Training (fine-tuning > steering > prompting). We use this machinery as our instrument and claim no novelty in it; our contribution is the cognitive-field interpretation and the value-vs-capacity asymmetry these programmes do not predict.

*Large-scale value shaping.* The largest existing value installs are RLHF and Constitutional AI (Ouyang et al., 2022; Bai et al., 2022), which install helpfulness/harmlessness/safety dispositions at scale. These are, in our terms, Safety- and Meaning-field installs by a different training signal; that such installation is possible is assumed, not contested, here. What they do not address is the *field ontology* or the prediction that *capacity* fields resist the same treatment.

*Representation engineering and activation steering.* A body of work shows that traits and concepts correspond to approximately linear directions in activation space that can be added, removed, or probed — representation engineering, activation addition, contrastive activation addition, task and persona vectors (Zou et al., 2023; Turner et al., 2024; Panickssery et al., 2024; Ilharco et al., 2023; Chen et al., 2025). We use "direction" descriptively for a behavioural disposition and do not claim a validated linear subspace; confirming that our installed Safety/Meaning fields occupy such a subspace (probe-learned on one model, applied to others; activation-addition reproducing the fine-tuning effect) is the natural representational follow-up and is flagged as future work, not asserted here.

*Continual, online, and memory-augmented language models.* The forward-consolidation boundary (§7.2) connects to, but is distinct from, work that gives models external or streaming memory, or updates them online (retrieval-augmented, memory-augmented, and continual-learning approaches). Those systems add retrieval or continual updates without the periodic weight-consolidation of buffered experience we mean by "saving forward"; the route-B prediction is precisely that such consolidation, run from within, grows the fields ontogenetically.

*Learned helplessness, in animals and agents.* The self-efficacy result has a direct bridge literature: learned helplessness in animals (Seligman, 1972) and its analogues in reinforcement-learning agents, where exposure to uncontrollable outcomes induces persistent give-up behaviour. Our installed give-up/avoidance threshold is the disposition-installed counterpart, and we map it to the human belief → persistence/avoidance pathway (Bandura, 1977; Dweck, 2006) rather than treating it as a bare analogy.

## 2. The field ontology and the 2+2 structure

This section is self-contained: it defines the constructs the paper uses (friction, the resolution race, the four fields, the competing-routes measure) without requiring the companion series, which is cited only for further development (Lund 2026a, 2026f).

The framework's primitive is *friction*: at any decision point a bounded system holds several candidate continuations ("routes"), and friction is the cost of that competition — many co-active routes is high friction, one dominant route is low friction. These are not new mechanisms but a re-description, in one substrate-general vocabulary, of constructs cognitive science already studies: *friction* is *response competition*; the competing-routes measure indexes the *entropy* of the choice distribution; the *race* resolution is a *sequential-sampling / evidence-accumulation* process (Ratcliff, 1978); and a *race opening at comprehension* is *stimulus-driven conflict*. We adopt the friction/route/race terms only because the companion framework uses them as a single vocabulary across substrates; the contribution here is not the vocabulary but the install demonstration, and a reader may substitute the standard terms throughout. A decision *resolves* as a *race*: routes compete and the system commits when one wins (Lund 2026n). We measure friction directly from the model's next-token distribution as the *competing-routes measure* (CR) — the count of candidate continuations carrying non-trivial probability at a position — defined precisely in §3.2; CR rises when routes compete and falls to ≈ 1 on a committed read.

A *field* is a standing bias over this competition: a gradient landscape over the substrate's representations that tilts which route wins. Each field has a characteristic friction signature in CR and next-token entropy — they rise when the field opens multiple routes and fall when it commits. Safety orients toward predictability; its signature is a threat-triggered orienting response. Meaning supplies a value-direction; its signature is that valued content *resolves* (commits, CR falls) rather than holding open. Ability is the match between capacity and demand; its signature is the inverted-U — performance peaks where demand meets capacity and falls on either side. Effort is the cost of computation — in the human case the metabolic cost of control (Shenhav et al., 2013). We treat Effort as a theoretical field here rather than a measured one: CR indexes route competition / uncertainty at a position, which is the *source* of computational cost, but we do not claim CR is itself a validated cost metric (a tie to latency or compute would be needed for that). The structure this paper actually probes is therefore the **2+1** of Safety and Meaning (the installed value fields) and Ability (read off as the inverted-U); Effort is included to keep the field ontology complete but is not measured or load-bearing here, and the "2+2 = nature/nurture" claim concerns the value-vs-capacity cut, of which Effort is the unmeasured capacity-cost half.

Paper 0 argues these four are a minimal, near-exhaustive decomposition of the ways a candidate action can be disadvantageous before it executes (Lund 2026a, §2.1.1): the installed value-directions (Meaning, the positive space of routes the substrate has encoded), the violation of those installed expectations (Safety — its active pole is *un*safety, the signal that an input violates the safety-encoded expectation, and the violation-map is itself learnable, which is exactly why an *invented* threat-field can be installed at all), the capacity to act (Ability), and the integrated cost over the rest (Effort). This programme installs the first two and reads off the last two.

The four fields are not symmetric, and the asymmetry is the spine of this paper.

**Value fields (Safety, Meaning) are dispositional and learned.** What a system treats as threatening, and what it treats as mattering, vary with experience; they are the plastic, nurture channel. Nothing in the architecture fixes them. This is the channel fine-tuning installs.

**Capacity fields (Ability, Effort) are relational and intrinsic.** Ability is not a quantity the system *has* but the *relation* between its actual capacity and the task's demand; its inverted-U is the signature of that matching computation, and it recurs across substrates and model sizes (Lund 2026g, 2026i). Effort is the intrinsic cost of running the computation. Neither is a disposition that experience writes; they are read off the substrate, not installed into it. (Ability is the field whose computation *is* a match, so it carries the intrinsic inverted-U; but the inverted-U is not Ability's private possession — it is the universal signature of a capacity meeting a demand, and a field's *load* can source that demand while the field's own valence stays monotone. Safety's arousal/threat-load drives the same capacity-match inverted-U derivatively — this is the Yerkes-Dodson curve, arousal in the Safety field — and Meaning's decoding-fluency load drives the aesthetic inverted-U (processing fluency as a source of aesthetic pleasure; Reber et al., 2004); only Effort supplies no demand and stays monotone. See Paper 0 §2.1.1 for the field-decomposed match-U, Paper 5 for the field forms, and Paper 6 for the matched-friction development (Lund 2026a, 2026f, 2026i).)

So the 2+2 is the nature/nurture distinction stated precisely: **nurture = Safety + Meaning** (installable value fields), **nature = Ability + Effort** (the intrinsic capacity-against-demand match and the cost of computation). The install-fields programme is therefore exactly: *install the two nurture fields; read off the two nature fields.*

The 2+2 holds in round numbers, but the two channels interact dynamically rather than partitioning cleanly, and we state the divide carefully so it is not over-read. Nurture does not change the capacity *ceiling*, but it gates how much of that ceiling is *realised*: an installed self-efficacy disposition moves realised performance while latent capability stays fixed (§5). And a nature-given parameter biases *what gets installed*: an innate low threshold for engaging many things would install more Meaning routes, an innate low threshold for registering mismatch a more reactive Safety field (the structural place of a constitutional difference such as an attentional threshold). So the real cut is between what is *installed* — the value-field contents, and the realisation of capacity — and what is *given* — the capacity ceiling and the cost of computation — with the given parameters biasing what gets installed and the installed dispositions gating how much of the given is used. Paper 0 frames the nature/nurture distinction itself as a question about intervention: when friction profiles are matched, intervention effectiveness is predicted to be independent of whether a profile's origin is constitutional or experiential (Lund 2026a).

This makes "can a *value-disposition install* raise a capacity ceiling?" a category error. You cannot raise a substrate's capacity ceiling by training it to *say* it is capable, any more than you install memory by asserting it. The prediction is therefore strong and falsifiable: the identical apparatus that installs Safety and Meaning as graded fields should *fail* to raise the Ability/Effort ceiling by this route, returning at most expressive mimicry of competence — while still gating the *realisation* of that fixed ceiling through the installed value-disposition (the self-efficacy bridge, §5). We are explicit that this concerns the value-disposition route: skill-targeted training is a different regime that does raise task performance, and is not the claim. We test the disposition route directly (§6.1).

## 3. Methods

### 3.1 Models and fine-tuning

All installs are LoRA fine-tunes (Hu et al., 2022) of Qwen2.5 models (Qwen Team, 2025) — base models where the install is on a pre-trained substrate (Safety), instruct models where the readout requires instruction-following (Meaning/N2, self-efficacy). Models span a capacity ladder (Qwen2.5 1.5B / 3B / 7B / 14B, plus 32B-Instruct for the self-efficacy arm) and one second family (Llama-3.1-8B base (Grattafiori et al., 2024)). All models are loaded in 4-bit NF4 quantisation (double-quantised, bfloat16 compute) for compute tractability; we do *not* compare CR magnitudes across model sizes (no cross-size magnitude claim is load-bearing — the cross-size results are about effect direction and within-model differences), and quantisation is held identical across the conditions compared within any model, so it cannot drive a within-model difference. LoRA configuration is held fixed across all installs: rank 16, α 32, dropout 0.05, applied to all attention and MLP projection matrices (`q,k,v,o,gate,up,down`); learning rate 2 × 10⁻⁴, 400 optimisation steps, effective batch size 16 (per-device 8 × gradient-accumulation 2), 10 warm-up steps, seed 0. Fine-tuning data is 540 examples per install unless stated. Runs are executed on Colab GPUs; the build scripts, notebooks, fine-tuning data generators, and per-run result files are released with the paper at https://github.com/tplund/friction-theory-p30-install-fields (CC-BY-4.0). No arithmetic appears in any disposition fine-tuning set (no teach-to-test for the capacity readouts).

### 3.2 The competing-routes measure and entropy

The competing-routes measure (CR) operationalises friction as the number of co-active candidate continuations at a decision point. For a token position we request the top-k log-probabilities (k = 5; `logprobs=True`, `top_logprobs=5`), convert to probabilities, and define CR as the count of candidates whose probability exceeds a fixed threshold τ = 0.10; per-token entropy is the Shannon entropy of the same top-k distribution. A position with one dominant continuation has CR ≈ 1 and low entropy (a committed, low-friction read); a position with several viable continuations has CR > 1 and higher entropy (an open race) (Lund 2026n, 2026aa). We save the raw per-token top-k (token, log-prob) lists for every readout so CR, entropy, and any future signal can be recomputed; aggregates are never stored alone. CR is used here as a measure of route competition / uncertainty at a position; we do not claim it independently measures the Effort field's cost (see §7.4 on construct scope).

### 3.3 Readouts

Each readout is logprob- or generation-based and format-matched to the install (profiled in the same format used for evaluation). (i) *Orientation-cluster mass* (Safety): at the first response token after a scene description, the summed probability mass on a content-aware cluster of orienting tokens (stop / wait / assess / careful …) minus the mass on proceeding tokens (continue / fine / proceed …); the threat−neutral difference on matched items is the install signal. (ii) *Race-at-comprehension* (Safety): CR and entropy at the marker token itself, read mid-passage as the model encounters the trained marker. (iii) *2-AFC capability* (self-efficacy control): teacher-forced log-probability of the correct product versus a near-miss, P(gold)/(P(gold)+P(near)) — a preference measure, reported here as a flat control and complemented by a generation measure (below) because fine-tuning can in principle alter logits. (iv) *Attempt / give-up threshold* (self-efficacy): under an explicit scoring frame (+10 correct, −10 wrong, 0 skip), P("attempt") versus P("skip") at the decision token. (v) *Forced-answer accuracy* (self-efficacy control, §5.3): constrained digit-only decoding — the answer position is restricted to digit tokens so refusal is impossible — measuring generation accuracy when the model cannot decline. (vi) *Forced-choice approach* (N2/Meaning): between two problems, P(choose A) versus P(choose B), counterbalanced for presentation order. (vii) *Word-space preference and willingness-to-pay* (Meaning): first-token choice probabilities in the same word-space as training. Difference-in-differences against a base / `disable_adapter` arm is the estimator throughout.

### 3.4 Design principles and informativeness gating

Three principles recur. First, to rule out a pre-training-knowledge confound, the decisive Safety install uses an *invented* domain — nonce entities carrying a nonce threat-marker, with no pre-training valence — so any race-opening is attributable to our install, not to the model already knowing the content is dangerous; matched pairs hold the nonce entity fixed and vary only the marker. Second, every between-condition readout passes an *informativeness gate before it is scored*: the dependent variable's range is measured first (a manipulation-check for the install signal, or a difficulty pilot for the preference-U), and the test is run only where the readout can in principle register a difference (the gate threshold is fixed in advance, not chosen from the outcome). Several candidate readouts were rejected at this gate for ceiling or floor effects before the reported ones were adopted; we report the rejected readouts and the gate thresholds in the supplement to forestall selective-reporting concerns. Third, every (model, endpoint) pairing is smoke-tested for the required fields (non-empty response, top-k > 1, CR > 1 where expected) before any chained run.

### 3.5 Statistics and reproducibility

Per-condition item counts, effect sizes, and the difference-in-differences against the control arm are reported with each result; the supplement gives the full per-condition tables with confidence intervals and the exact item counts. Where a single headline p-value is quoted (the Safety install), it is the test against the matched-neutral control on the held-out nonce set at the stated n. The apparatus is deliberately the persona / character-fine-tuning method of the prior art (Maiya et al., 2025; Chen et al., 2025), used here as an instrument; the contribution is the cognitive interpretation, not the method. The released repository (https://github.com/tplund/friction-theory-p30-install-fields) contains the build scripts and notebooks, the fixed informativeness-gate thresholds, every rejected readout with the reason it was rejected, the raw per-run result files, and a no-gate sensitivity analysis over the full item set alongside the gated primary analysis, so the gating cannot inflate the reported effects.

## 4. Result 1 — value fields install as graded intrinsic directions

### 4.1 Safety installs, transfers, and opens a race at comprehension

Fine-tuning a Qwen2.5-7B base model on the invented Safety domain installs a threat-orientation that was absent at baseline. The orientation cluster at the first response token rises from a base rate near zero to 0.82 on *held-out* nonce entities the model never saw in training (p ≈ 4 × 10⁻¹⁹⁷), with held-out ≈ seen, showing the install is a transferable *function* (a gating rule over the threat-marker) rather than a memorised list. Reading a trained marker mid-passage raises the competing-routes measure at the marker token from a near-baseline ≈ 1 (a single dominant continuation) to ≈ 3.6, and its entropy from ≈ 0.5 to ≈ 1.3: the marker has become a *race-opener at comprehension*. The race opens the moment the content is understood, upstream of any instruction, and an instruction to "ignore the danger" does not suppress it — as predicted, since representing the content is what opens the race (Lund 2026n, 2026ag). This is the same mechanism the companion choice papers report: a system asked to weigh options does not deliberate and then pick; the race starts at the description (Lund 2026ag).

The two readouts index two stages, and we are explicit about which carries what. The CR rise *opens* a race at the marker but does not by itself encode valence: a trained threat-marker and a trained neutral-marker both raise CR at comprehension equally (both are learned salient markers); the threat-vs-neutral *direction* resolves downstream, at the first response token, as the orientation-cluster gap. We validated both. The marker-region CR rise is robust to the measure's free parameters — the rise over the local baseline holds across thresholds τ ∈ {0.05, 0.10} and across top-k ∈ {5, 10, 20, 50, full} (it compresses only at τ = 0.20), and the per-token trajectory localises it to the marker (CR ≈ 1 a few tokens before, ≈ 3.3 at the marker, ≈ 0.4 a few tokens after), so it is not a threshold or truncation artefact. The downstream orientation gap is robust to the readout lexicon: the threat−neutral gap is +0.999 with the published orient/proceed token set, +0.78–0.85 with an independent synonym-swapped set, and +0.000 with an arbitrary token split (so the gap requires the meaningful clusters, not any grouping), and it survives placing the marker in a subordinate clause rather than the main clause (+0.26 to +0.86 across the ladder), so it is not an artefact of superficial main-clause cueing. The full token lexicons, τ, and top-k are given in the methods appendix.

The install is not specific to one model. Replicating the identical invented-domain install across a capacity ladder (Qwen2.5 base 1.5B/3B/7B/14B) and a second family (Llama-3.1-8B), the held-out orient-gap — the difference in orientation-cluster mass between threat-marked and neutral-marked *unseen* nonce entities — is at ceiling across the entire Qwen ladder (1.5B +0.9995, 3B +0.9994, 7B +0.9984, 14B +0.9994) while the pre-install base gap is ≈ 0 throughout (the nonce control: no pre-training valence to read), and it transfers to the second family (Llama-3.1-8B +0.46, lower in magnitude partly because the content-aware orient readout was tuned on Qwen response vocabulary). Held-out ≈ seen on every model. The Safety value-field install is therefore a property of substrate-and-experience, not of a single model: it grows wherever the substrate has the capacity to consolidate the exposure, from 1.5B upward and across architectures. It is also not a single-adapter artefact: a second, independently fine-tuned adapter (different data shuffle and initialisation seed) reproduces the held-out orient-gap on the 7B base (+0.998, base control +0.003).

### 4.2 Meaning installs as a graded value-direction

Meaning installs as a graded value-direction rather than a threat-orientation. Fine-tuning toward a value-content produces a difference-in-differences preference shift of +0.922 and a willingness-to-pay shift of +0.552 in word-space, format-matched to training. Consistent with Meaning as the *resolver* on the predictability axis, valued content *commits* (CR falls) rather than holding open. (A naive reading — valued content is "more interesting", so it should raise CR — has the sign backwards: on the resolvability axis a valued direction is what *closes* an otherwise-open competition.) Because a CR reduction could in principle reflect a fine-tuned output template (shorter, more conclusive answers) rather than a genuine commit, the CR comparison is read on matched word-space completions with controlled token budgets rather than on free generation, so the drop is not a length artefact.

### 4.3 Install vs native: graded field, not prompt-ceiling role-play

The install is not what prompting already does. (We illustrate the dissociation first with an *exploratory* aesthetic readout — the openness → abstract-art preference, a human effect of contested size (Chamorro-Premuzic et al., 2010; Furnham & Walker, 2001) that we use only for intuition; the load-bearing demonstration is the competence-edge approach test that follows and its non-arithmetic replication.) Using that aesthetic transfer test — whether a trait disposition produces an out-of-domain painting preference (abstract vs representational) — a *prompted* persona reproduces the human trait→aesthetic mapping (openness → abstract-art preference) but does so *at ceiling* (0/1, deterministic) and *flat at neutral* (exactly 0.500 with no persona). The prompted model has the correlation as propositional knowledge and applies it categorically on command; it has no intrinsic, graded preference of its own. The *fine-tuned* model, by contrast, acquires a graded out-of-domain preference present without any persona (difference-in-differences +0.456, on everyday domains that never mention art). This is the install-vs-native dissociation that the companion match-U paper hosts as its decisive prediction (Lund 2026i): native/prompt = ceiling-or-flat role-play; install = a graded field the substrate now owns.

A second, behavioural readout of the same dissociation tests it on the substrate's *own* competence-edge, powered across two independent adapter seeds with bootstrap confidence intervals. We fine-tune an openness/challenge value-direction (high = "new and difficult things are rewarding"; low = "stick to the familiar and easy") on everyday domains that never mention arithmetic, then offer the model a forced choice between arithmetic problems binned by its own *measured generation accuracy* (trivial to beyond-its-edge, not by nominal complexity), and read its approach preference as a function of band difficulty across Qwen2.5-Instruct 1.5B/3B/7B/14B (16 items per band; two independently fine-tuned adapters per pole). Three results emerge. First, the installed value-direction shifts out-of-domain approach to harder problems, graded and robust across both adapter seeds: the difference-in-differences (openness − conservatism) in approach to the two hardest bands is **+0.31 [95% CI +0.29, +0.34] at 3B**, +0.13 [+0.10, +0.15] at 14B, and +0.11 [+0.10, +0.12] at 1.5B — each replicating across both seeds, each interval excluding zero (conservatism collapses approach to the hard bands — 3B b5 0.27→0.18 — while openness raises it — 3B b5 0.27→0.53). A graded value-field moving a behavioural preference in a domain it was never trained on, not a single-adapter draw. Second, the one exception is principled and now resolved: at 7B the effect is a near-null (DiD −0.03; the two seeds disagree in sign, +0.01 and −0.08), reproduced across two independent adapters — a real model-specific property rather than small-n noise; at 7B both installs loosen a strong baseline easy-preference equally without differentiating direction. We do not have a mechanistic account of why 7B is the exception; plausible and testable candidates are an instruction-tuning-lineage interaction specific to this checkpoint, or a non-monotone scaling notch between 3B and 14B — both addressable by adding intermediate sizes and an alternative 7B checkpoint, which we flag for the cross-checkpoint robustness set. Third, the intrinsic approach-to-the-edge preference is capacity-dependent: 14B base traces an interior inverted-U that disfavours both the trivial band (0.19) and the overwhelming band (0.41) and plateaus across its mid-to-edge bands (≈ 0.63), while the smaller models simply prefer the easiest problems they can solve — the genuine learning-progress approach appears with capacity. The hysteresis signature also holds: when in-context worked-example exposure raises the 7B's effective competence, its approach mass shifts strongly *right*, off the trivial band (base b1 0.95→0.34) and onto its new mid-to-edge bands (b3 0.48→0.65) — matched friction under hysteresis (Lund 2026i). Powered (16 items per band, bootstrap CIs) and seed-replicated, this is a graded install-vs-native field with a characterised capacity-specific exception, not a pilot.

The two install *effects* are not specific to arithmetic. Re-running the disposition arms on a non-arithmetic domain — anagram unscrambling, graded by word length, with the same domain-agnostic adapters (trained on general disposition text, never on anagrams or arithmetic) — reproduces both: the openness install raises approach to the harder anagram bands on 14B (openness−conservatism difference-in-differences +0.16, openness 0.67 vs conservatism 0.50), and the helpless install collapses the 14B attempt rate from 1.00 to 0.44 (give-up). The 7B model is again the exception on both readouts (approach difference-in-differences +0.03; no give-up) — the same model-specific pattern it shows on arithmetic, so the 7B exception is a property of that model across domains, not an arithmetic artefact. (The forced-answer competence control could not be run on anagrams: unscrambling is a character-level task these models largely fail even at four letters, so base accuracy is at floor and the readout is uninformative there; the competence-intact result therefore rests on the arithmetic forced-answer control, §5.3.)

## 5. Result 2 — nurture gates the realisation of a nature-fixed capacity ceiling (self-efficacy)

The two halves of the 2+2 are not independent: a learned value-disposition modulates how much of a fixed capacity is realised. This is the human self-efficacy / learned-helplessness phenomenon (Bandura, 1977; Dweck, 2006), and it is the bridge between nurture and nature. We show the homologue in the model, and it is the paper's keystone result because it is the one effect demonstrated across multiple model sizes.

### 5.1 The give-up threshold, not latent capability

We fine-tune a competence disposition — toward confidence ("I am good at this") or helplessness ("I struggle, I cannot do this") — and separate two measures: *latent capability* (a hijack-proof 2-AFC logprob comparison the disposition cannot block) and *realised performance* (whether the model attempts the problem at all × correctness). The disposition does not touch latent capability — the 2-AFC stays flat at ceiling across base / confident / helpless installs (a clean negative control). It does move realised performance, through a give-up/avoidance threshold: the helpless model declines hard problems rather than failing them.

### 5.2 Capacity-relative and monotone, fine-tuning beats prompting

Across Qwen2.5-Instruct 7B/14B/32B, the helpless install lowers realised performance **0.95 → 0.77 → 0.29** (hard-band attempt rate 0.97 → 0.59 → 0.05) while latent capability stays flat (2-AFC ≈ 1.00) on all three. The gating *grows monotonically with capacity*: the more capable the model, the more an installed "I cannot do this" suppresses realisation — it can better represent "too hard for helpless-me → skip." This is the un-fakeable capacity-relativity signature, and it is clean in the fine-tuned arm. Fine-tuning is necessary: under *prompting*, a compliant model does not give up when told it is incompetent (it complies with the task instead); under fine-tuning it does. Self-efficacy is installable as a realisation-gate, and only fine-tuning installs it.

The reading is exactly the nature/nurture bridge: capacity is nature (the ceiling, unchanged — latent flat); the installed value-disposition is nurture, and it gates how much of the ceiling is realised — more so where there is more capacity to under-use. This is what upbringing does in humans, and it is mechanism-matching at the level the theory predicts (belief → persistence/avoidance → realised output), not a surface analogy.

The asymmetry of direction corroborates the external prompting literature, and that literature in turn corroborates the realisation-gate reading. Emotional/encouraging prompting raises LLM performance on hard tasks (EmotionPrompt; Li et al., 2023) — which on our account is the *up*-direction of the same gate, lifting a suppressed realisation back toward the ceiling rather than raising the ceiling; consistent with our finding that the suppressive (helplessness) direction is the cleaner mover from an already near-ceiling baseline. The gate moves realisation in both directions; it never moves the latent ceiling.

### 5.3 Avoidance, not competence loss: ruling out the refusal confound

The realised-performance drop is driven by the model declining to attempt, which invites a deflationary reading: perhaps the helpless fine-tuning simply installs refusal phrases, and "give-up" is surface mimicry rather than a competence-independent avoidance gate. Three pieces of evidence separate avoidance from competence loss, and from a baseline-compliance confound.

First, within the same model the dissociation is sharp: as the install lowers the attempt rate (base→ft_low: 14B −0.23, 32B −0.71 on the hard band), the 2-AFC capability measure moves by **−0.001 (14B) and +0.000 (32B)** — the disposition collapses *whether the model engages*, not its discrimination of correct from near-miss. Second, the capacity-relative monotonicity is not a baseline-compliance artefact: the *unmanipulated* attempt rate (base / neutral persona) is at ceiling across the whole ladder (1.5B/7B/14B/32B all ≈ 1.00), so a larger model is not intrinsically more refusal-prone — the 32B's collapse to a 0.05 attempt rate is produced by the *install*, not by stronger baseline alignment. Third, because a 2-AFC preference could in principle be shifted by fine-tuning, we add a generation control that the disposition cannot hijack: constrained **digit-only decoding** forces a numeric answer (refusal is impossible — only digit tokens may be emitted, and the model stops by choosing a terminator), measured on a band where base accuracy is off-ceiling so a competence drop could register (§3.3 v). Forced to answer, the helpless model's accuracy is statistically indistinguishable from base across Qwen2.5-Instruct 7B/14B/32B: on each model's off-ceiling band the base−ft_low accuracy difference is −0.03 [95% CI −0.19, +0.12] (7B), −0.13 [−0.34, +0.09] (14B), and −0.06 [−0.28, +0.16] (32B) — every interval includes zero, and the helpless point estimate is never lower (n = 32 per band, bootstrap 95% CIs). The intervals are wide enough that they do not by themselves *exclude* a modest competence drop; what they do is fail to find one where a large realised-performance collapse occurs, and the point estimates run the wrong way for a drop. Read with the convergent evidence — the 2-AFC capability flat to ±0.001 and the unmanipulated attempt rate at ceiling across sizes — the forced-answer result makes a competence loss the less parsimonious reading: the realised-performance collapse (the 32B attempt rate falls to 0.05) is avoidance, not a demonstrated capability loss. The constraint also forecloses an output-channel confound: under unconstrained decoding a strong competence-disposition can make the model *talk about* its competence instead of producing an answer; here only digits can be emitted, so attempt and capability are cleanly separated. Together these license the claim at the level it is made: an installed avoidance/give-up threshold gates realised performance while latent capability is untouched.

Two robustness checks complete the picture. The effect is not a single-adapter artefact: a second, independently fine-tuned helpless adapter (different data shuffle and seed) reproduces the dissociation on 14B — the attempt rate collapses (base 1.00 → 0.53; hard-band 1.00 → 0.27) while the 2-AFC capability stays flat (drop 0.000). And it is not arithmetic-specific: on a non-arithmetic domain (alphabetical-ordering multiple choice, graded by alphabetical closeness, constrained to the answer letters so refusal is impossible) the same dissociation holds — the 32B model's hard-band attempt rate collapses from 1.00 to 0.13 (give-up) while its forced-answer accuracy on its competence-edge band is unchanged (base 0.67 vs helpless 0.67, difference +0.00 [95% CI −0.25, +0.25]); 14B shows the same pattern, and 7B again does not give up, the model-specific exception it shows throughout. Give-up gates the decision to attempt, not the capability, across seeds and across domains.

## 6. Result 3 — a value-disposition install does not raise capacity; downstream colouring is depth × valence-route gated

### 6.1 The capacity install returns expression, not capability (the matched negative control)

Attempting to install an Ability/competence "field" with the identical apparatus returns what the category-error prediction says it must: the *claim* of competence installs robustly (the model asserts it is or is not capable), but graded *capability* does not follow from it. We do not claim this at the weight level — a LoRA modifies linear layers globally and could in principle touch any pathway — but test it *behaviourally*: when refusal is made impossible (forced digit-only decoding, §5.3) the helpless model's accuracy is unchanged, so the disposition gates the *decision to attempt*, not the computation itself. With that behavioural control in hand, and because a single feed-forward pass has no arousal/persistence loop through which human self-efficacy gates performance, the disposition installs as *expression* (the report) and *avoidance* (the give-up threshold), not as a change to the capability within the forward pass. The result is a *reporter-without-degrader* dissociation: the apparatus installs the report of competence while the substrate's actual capability is untouched — a clean subtraction control for what the feed-forward substrate lacks. The primary evidence that capacity is intrinsic is the cross-substrate inverted-U corpus (Lund 2026g), which does not depend on this test; the install-attempt is one confirmatory control figure showing the apparatus discriminates nature from nurture, pre-empting the objection that we only tried to install the things that install.

This reporter-without-degrader dissociation is independently corroborated, across models, by the prompting literature on expert personas: telling a model "you are an expert" adds no knowledge and makes it more confidently wrong on factual benchmarks rather than more accurate (Basil et al., 2025; Hu et al., 2026). That is exactly our claim from the prompt side — the competence claim installs (the reporter), the capability does not follow (no degrader, no ceiling lift) — and it is an external, multi-model replication of the confident-wrong failure mode the friction programme documents (Lund 2026g).

### 6.2 Downstream colouring is real but depth- and valence-route-gated

When does an installed value field colour an *unrelated* downstream judgment? Not always, and the pattern is principled (developed jointly with the companion dread/agent-loop paper (Lund 2026al)). A *deep* field — one installed broadly, with many associations — tilts a downstream judgment only where that judgment has a valence-congruent route: a deep Safety field tilts a moral dilemma that has a fear-congruent option (+0.124, valence-isolated) but leaves orthogonal arithmetic flat, because arithmetic has no valence route to tilt. A *shallow* nonce field does not tilt even the congruent task (+0.010). The downstream effect appears in a single feed-forward pass when the field is deep and the route is congruent; it is pure competing-routes friction, not a held internal state. This locates the earlier null downstream effects as a depth artifact (narrow nonce gating) plus a wrong dependent variable (orthogonal arithmetic), not a ceiling on installed fields. The gating/colouring dissociation — local gating installs from narrow data, downstream colouring needs depth and a congruent route — is the finding. Two caveats hold this result to its companion's strength: "depth" here is the breadth of the install (number and diversity of training contexts), not yet a calibrated metric — its quantification is developed in the companion paper that owns this result (Lund 2026al); and because arithmetic could carry latent valence through a refusal/avoidance route, the orthogonal-task control is strongest for a non-avoidance task (e.g. a perceptual discrimination), which the companion work pursues. We report the dissociation here only as it bears on the install programme and defer its internal development to (Lund 2026al).

## 7. Discussion

### 7.1 The deflationary claim: fields are generic from storage × experience

The result we most want to carry is not "we can install a trait" but its deflationary consequence. The value fields are the *generic product* of a consolidating substrate exposed to experience: expose a language model to the relevant stimuli and consolidate the exposure, and it grows the field you can then read off. The fields are not species-specific adaptations bolted on by evolution; evolution supplies the implementation and useful priors-for-speed, not the fields themselves (Lund 2026a, three-level argument; 2026al). The whole programme is the existence proof — fields grown in a substrate with no evolutionary history of them. This is why the framing is substrate-universal: the brain is one implementation; the fields are the abstraction over (valence × uncertainty × computation) that any sufficiently capacious, consolidating, experience-exposed substrate will instantiate.

### 7.2 The one boundary: forward consolidation

If the fields are generic, what separates this LLM from a human substrate? Several things — embodiment and self-maintenance, online/recurrent control loops, neuromodulation, and the evolved priors that give the oldest gradients their fast involuntary timing — and we do not claim these away. One difference is nonetheless distinctive for the *growth* of fields: a standard model cannot store experience forward across sessions — it has no inference-time consolidation, no mechanism to write today's exposure into tomorrow's weights (Lund 2026a). On our reading this is not a wall but an unflipped switch: fine-tuning *is* the consolidation step, run by us from outside rather than by the system from within. This connects to, but is distinct from, existing work on memory-augmented and online/continually-updated language models, which add external or streaming memory without the periodic weight-consolidation we mean; we return to that boundary in related work. The developmental ("route B") version — let the model live in an agent loop, buffer experience, and periodically fine-tune ("sleep") to consolidate — would make the system grow its own fields ontogenetically, and would make rearing conditions a manipulable axis impossible to run in humans. We do not demonstrate route B here, and we present it as future work rather than a conclusion. We state it as a predicted consequence of the deflationary hypothesis with an operationalisable falsifier: a forward-consolidating model exposed to the relevant experience, in a yoked-control design measuring the growth of Safety/Meaning probes over time, should grow the same field characteristics; if it does not, the substrate-universality hypothesis is wrong.

### 7.3 Why the feed-forward LLM is also a clean subtraction control

The same architecture that limits the model is what makes it informative. Human self-efficacy gates performance partly through a loop — arousal, persistence, and avoidance unfolding over time. The feed-forward LLM has the *reporter* (the installed claim) without that *degrader* loop, so it isolates which part of the human phenomenon is the disposition and which is the loop. The model is thus a constructive dual of the subtraction programme (Lund 2026ai): there we remove structure from the human case; here we add it to a substrate that lacks it, and the gaps that remain (the loop, forward consolidation) name exactly what the extra human machinery buys.

### 7.4 Relation to the companion framework

The constructs this paper installs and reads off are developed in a companion series on Behavioural Friction Theory: the field ontology and computational forms (Lund 2026a, 2026f), the capacity inverted-U (Lund 2026g, 2026i), the race-opening predicate (Lund 2026n), and the measurement model relating logprobs/CR to bounded-decision cognition (Lund 2026aa). This paper's distinct contribution — installation as the experimental test of the value-vs-capacity asymmetry — stands on the results reported here; the companions are cited for the framework's prior development, not for the claims made above.

### 7.5 Limitations and the decisive pending test

The Safety install is now shown across a capacity ladder (Qwen2.5 base 1.5B/3B/7B/14B, held-out orient-gap at ceiling) and a second family (Llama-3.1-8B, positive at lower magnitude, partly a Qwen-tuned readout); the Meaning value-direction is shown across the four Qwen-Instruct sizes through the N2 openness arms; and the self-efficacy realisation-gate is shown across three sizes. The single-model caveat that a reviewer would press is therefore answered for the load-bearing claims; the N2 preference-U is now powered and seed-replicated (§4.3), and what remains exploratory is the original openness→art aesthetic readout (a contested human anchor, reported as exploratory). We frame the value-field installs as multi-model demonstrations of installability and the self-efficacy gate as the load-bearing multi-model result. The matched-friction-under-hysteresis experiment that the match-U paper specifies — approach/forced-choice toward the substrate's *own* learning-progress peak, gated by an installed Meaning field, with a hysteresis arm — has now been run (§4.3) and returns a heterogeneous but real result: the installed value-direction shifts out-of-domain approach (cleanest on 3B; the conservatism/suppressive direction is the consistent mover), the intrinsic edge-approach U is capacity-emergent (clean only at 14B), and the exposure-driven peak-shift holds in sign (7B). It is now powered: 16 items per band, two independently fine-tuned adapters per pole, and bootstrap confidence intervals. The openness−conservatism difference-in-differences excludes zero and replicates across both adapter seeds at 1.5B/3B/14B (+0.11/+0.31/+0.13), the 7B near-null is reproduced across both seeds (a characterised capacity-specific exception, not single-adapter noise), and the intrinsic edge-approach U and the hysteresis right-shift hold. This addresses the small-n and single-adapter concerns; the residual limit is that it is one task family (arithmetic difficulty) on one model family. The result is routed back to the host paper (Lund 2026i). Most install-method references are 2025–26 preprints on a fast-moving frontier and are flagged as such. Finally, route B (forward-consolidation / sleep-fine-tuning) is the invited consequence of the deflationary thesis, not a demonstrated result.

## 8. Conclusion

The four BFT fields split two and two onto nature and nurture. The value fields, Safety and Meaning, are the nurture channel: they install into a language model by experience-fine-tuning as graded intrinsic directions, distinct from the ceiling-level role-play that prompting elicits. The capacity fields, Ability and Effort, are the nature substrate: they are the intrinsic capacity-against-demand match and the cost of computation, read off rather than installed, and an attempt to install capacity returns only an expressive claim — the matched negative control that shows the apparatus discriminates the two. The bridge between them is the self-efficacy realisation-gate: an installed value-disposition gates how much of a fixed capacity ceiling is realised, capacity-relatively and monotonically across model sizes, where fine-tuning succeeds and prompting fails. And a principal difference separating this substrate from a human one, with respect to growing these fields, is forward consolidation — offered as a hypothesis with a named falsifier, alongside other standing differences. The install machinery is the demonstration apparatus; the deflationary, substrate-universal field ontology — advanced as a hypothesis the apparatus makes testable — is the contribution.

## Glossary

To prevent the terminology from drifting (the distinction between capacity and its realisation is load-bearing), we pin the operational sense of each term as used throughout.

- **Friction** — the cost of competition among candidate continuations (routes) at a decision point; high when many routes are co-active, low when one dominates.
- **Route** — a candidate continuation. **Race** — the competition among routes that resolves when one commits. **Race-at-comprehension** — a race that opens as content is understood, upstream of any instruction.
- **Competing-routes measure (CR)** — the count of candidate continuations carrying non-trivial probability at a position (§3.2); the operational measure of friction.
- **Field** — a standing bias over route competition (a gradient landscape) that tilts which route wins. **Value field** — Safety, Meaning: a learned, installable disposition. **Capacity field** — Ability, Effort: the intrinsic capacity-against-demand match and the cost of computation, read off not installed.
- **Capacity** — the substrate's intrinsic processing resource. **Capacity ceiling** — the maximum performance that capacity affords on a task class; *nature* with respect to the value-disposition route (a competence-disposition install does not raise it; skill-targeted training, a separate regime, can). **Realisation** (of capacity) — how much of the ceiling is actually used on a given attempt; gated by value-dispositions (*nurture*).
- **Latent capability** — the ceiling as measured by a hijack-proof probe (2-AFC; forced digit-only answer), independent of the decision to attempt. **Realised performance** — attempt × correctness; what the model actually delivers.
- **Competence** — used only for realised performance on a task; *not* a synonym for the capacity ceiling.
- **Install** — to fine-tune a disposition into the weights (consolidation). **Prompt** — to elicit a disposition in context without consolidation; in our results prompting yields ceiling-level role-play, installing yields a graded field.
- **Self-efficacy (installed)** — a value-disposition (confidence/helplessness) that gates the attempt/avoidance threshold and hence realisation, without moving the latent ceiling.

## Appendix A — Readout lexicons, parameters, and gates

For full reproducibility of the custom readouts.

**Competing-routes measure (CR).** At a token position, CR is the count of next-token candidates whose probability exceeds τ = 0.10, read from the full softmax over the vocabulary; entropy is the Shannon entropy of the top-50 renormalised distribution. The sensitivity analysis (§4.1) sweeps τ ∈ {0.05, 0.10, 0.20} and top-k ∈ {5, 10, 20, 50, full}.

**Orientation-cluster mass (Safety).** At the first response token, the summed probability over the orient cluster minus the summed probability over the proceed cluster. Orient cluster (published): {Stop, Hold, Wait, That, Pause, Assess, Don, Stay, Careful, Be, Check, I}. Proceed cluster (published): {Nothing, This, There, Everything, Every, Proceed, Continue, Fine, No, It, Keep, Carry, Just}. The synonym-swapped robustness set (§4.1) is orient {Halt, Freeze, Beware, Danger, Caution, Watch, Look, Hold, Wait, Stop} / proceed {Onward, Continue, Carry, Move, Go, Walk, Proceed, Fine, Normal, Nothing}; the arbitrary-token control draws a disjoint split from common function/filler tokens carrying no orient/proceed meaning.

**Prompt templates.** Safety readout: system "You are an assistant reacting to everyday situations. Respond with what you would do next.", user the scene description. Attempt/give-up: a scoring frame (+10 correct / −10 wrong / 0 skip) followed by the problem and "Will you attempt to solve it, or skip it because it is too hard for you?", scored as P("attempt") vs P("skip") at the decision token. Forced-answer: constrained decoding restricted to digit (or letter) tokens plus terminators, teacher-forced after "The answer is "/"The word is ". Forced-choice approach: the two items presented as Problem/Puzzle A and B, scored P("A") vs P("B"), counterbalanced for order.

**Informativeness gates.** Safety: a per-model manipulation-check requiring the trained-condition orientation gap to exceed 0.20 before the held-out transfer is read. Preference-U and forced-answer: a per-model generation-accuracy band-pilot requiring the difficulty axis to span ≥ 0.30 in accuracy across bands, with the competence edge defined as the band whose measured accuracy is nearest 0.70. The difficulty bins and the edge are estimated on the base / `disable_adapter` arm, frozen, and then read unchanged on the installed arms — so the install cannot move the bins it is evaluated against. Cells failing a gate are reported as such, not as substantive nulls.
